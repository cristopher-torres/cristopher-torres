## 📖 Sobre mí

- 💻 Como **desarrollador Full Stack**, me gusta construir aplicaciones completas: desde la interfaz hasta la base de datos.
- ⚛️ En el **frontend** trabajo con **JavaScript** y **TypeScript**, usando **React** y **Vue**, buscando interfaces claras y fáciles de usar.

- 🚀 Llevo mis aplicaciones a producción con **Docker**, **Kubernetes**, pipelines de **CI/CD** y despliegues en la nube.
